🚐 Guide bénévole Runner FB26

3 étapes simples

Avant le festival, il faut d’abord répondre au formulaire, puis installer l’application, puis apprendre les bases d’utilisation. Dans cet ordre. Sinon c’est le bazar, et le bazar conduit au tableur maudit.

Formulaire bénévole

Remplis les infos demandées. Indique tes préférences et tes souhaits.
Tes choix sont consultatifs. Ils seront pris en compte autant que possible, mais ils ne peuvent pas être garantis.
Valide l’envoi du formulaire. Une fois envoyé, tes réponses seront utilisées pour préparer le planning.
📝 Répondre au formulaire

Installation

Ouvre le lien avec Chrome. Si possible, utilise Chrome pour éviter les surprises.
Appuie sur le menu ⋮. Ce sont les trois petits points en haut ou en bas selon le téléphone.
Choisis “Ajouter à l’écran d’accueil”. Selon le navigateur, le texte peut aussi être “Installer l’application”.
Valide l’installation. L’icône Runner FB26 apparaîtra comme une vraie application.
Si Google Play Protect affiche une alerte, appuie sur “Plus de détails”, puis sur “Installer quand même”.
Ouvre le lien avec Safari. Sur iPhone, l’installation sur l’écran d’accueil passe par Safari.
Appuie sur le bouton Partager. C’est l’icône avec un carré et une flèche vers le haut.
Choisis “Sur l’écran d’accueil”. Fais défiler la liste si l’option n’apparaît pas tout de suite.
Appuie sur “Ajouter”. L’icône Runner FB26 sera ajoutée comme une application.
Sur iPhone, le mode hors ligne peut être plus capricieux. Ouvre l’application une première fois avec du réseau avant le festival.
🚐 Ouvrir l’application

Utiliser Runner FB26

Accueil
Le créneau en cours est cliquable pour voir qui est sur ce créneau. L’icône personnage à côté de “connecté en tant que” permet de changer de vue utilisateur.
Mes créneaux
Chaque carte est cliquable pour voir la composition du créneau. L’icône imprimante permet d’imprimer tes créneaux, un jour précis ou le planning complet.
Planning
Le planning affiche les créneaux par jour. Chaque carte est cliquable pour voir les détails et les personnes présentes.
Contacts
Les cartes sont cliquables pour voir les créneaux de chacun. Pour les référents, il suffit d’appuyer sur le téléphone pour appeler directement.
Choisis ton profil bénévole. Sélectionne ton nom pour afficher tes informations personnelles.
Consulte tes créneaux. Tu peux voir tes horaires, ton rôle et les informations associées.
Utilise les cartes cliquables. Accueil, Mes créneaux, Planning et Contacts donnent accès aux détails.
Ouvre l’application avec du réseau au moins une fois. Ça permet de charger les dernières données avant d’avoir besoin du mode hors ligne.
