📲 Installer l’application Runner FB26

Guide d’installation

Cette page explique comment ajouter l’application sur l’écran d’accueil du téléphone. Une fois installée, elle s’ouvre comme une vraie application.

Android Utiliser Chrome de préférence.
iPhone Utiliser Safari obligatoirement.
🚐 Ouvrir l’application 🔎 Vérifier le manifest

Android

🤖

Installation avec Chrome

La méthode recommandée pour éviter les alertes inutiles de certains navigateurs.

Ouvre le lien avec Google Chrome Évite Samsung Internet si possible : il peut afficher une alerte Play Protect.
Appuie sur le menu ⋮ Le bouton est en haut ou en bas selon le téléphone.
Choisis “Installer l’application” Si tu vois “Ajouter à l’écran d’accueil”, ça marche aussi.
Valide avec “Installer” ou “Ajouter” L’icône Runner FB26 apparaît ensuite sur l’écran d’accueil.
Si Samsung Internet affiche “Appli non sécurisée bloquée”, ce n’est pas l’application qui est dangereuse : utilise Chrome pour l’installation.

iPhone

🍎

Installation avec Safari

Sur iPhone, l’ajout à l’écran d’accueil se fait depuis Safari.

Ouvre le lien avec Safari Sur iPhone, Chrome ne propose pas toujours l’installation correcte.
Appuie sur le bouton Partager C’est l’icône avec un carré et une flèche vers le haut.
Choisis “Sur l’écran d’accueil” Fais défiler la liste si l’option n’apparaît pas tout de suite.
Appuie sur “Ajouter” L’icône Runner FB26 sera ajoutée comme une application.
Sur iPhone, le mode hors ligne peut être plus capricieux. Ouvre l’application une première fois avec du réseau avant le festival.

À savoir

Est-ce une vraie application du Play Store ou de l’App Store ?

Non. C’est une application web installable. Elle se lance comme une application, mais elle n’a pas besoin de passer par un store.

Faut-il internet ?

Oui pour récupérer les dernières données. Certaines informations déjà chargées peuvent rester disponibles hors ligne, selon le téléphone.

Pourquoi utiliser Chrome sur Android ?

Chrome gère mieux l’installation PWA. Certains navigateurs Android ajoutent des alertes ou créent un simple raccourci moins propre.

Pourquoi utiliser Safari sur iPhone ?

Apple impose le moteur Safari pour les applications web installées. L’ajout propre à l’écran d’accueil se fait donc via Safari.
